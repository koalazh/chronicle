# 历史文档归档

这里保存已经完成的阶段性计划、迁移说明、旧验收记录和一次性研究材料。它们用于追溯决策和证据，不是当前产品入口，也不能覆盖当前源码或 [`../ACCEPTANCE.md`](../ACCEPTANCE.md) 的结论。

## 目录

| 目录 | 内容 | 使用方式 |
| --- | --- | --- |
| [`versions/v2/`](versions/v2/) | 早期 Worldline/Branch 方法与迁移 | 仅在处理旧数据或追溯历史时阅读 |
| [`versions/v3/`](versions/v3/) | 早期运行和验收记录 | 仅作为历史现场证据 |
| [`versions/v4/`](versions/v4/) | 旧架构迁移边界 | 仅用于兼容代码和迁移审计 |
| [`versions/v5/`](versions/v5/) | Volume 基础阶段的实施、迁移和验收 | 仅用于追溯基础能力的形成 |
| [`versions/v6/`](versions/v6/) | 连续判断、Attention、Deliberation 和最终实跑记录 | 仅用于追溯当前能力的演进证据 |
| [`spikes/`](spikes/) | 已结束的一次性前端维护性分析 | 不作为当前前端合同 |

## 归档原则

- 归档文件保留当时的版本标签、分支、commit 和失败边界，不能改写成“当前状态”。
- 如果归档内容与当前源码冲突，以当前源码和当前文档为准。
- 归档文件不保存 Secret；临时数据库、Gateway 日志和模型正文只保留在受控的本地或可恢复的临时位置。
